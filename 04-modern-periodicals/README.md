# T04 近现代刊物 / Modern Periodicals

目标：整理近现代净土杂志与出版物。

Goal: organize modern Pure Land periodicals and publications.

重点：《净土》《净土宗双月刊》《明伦》《念佛感应录》《当代念佛感应集》《念佛感应见闻记》《e世纪往生传》等。

Focus: publications such as *Jingtu*, *Pure Land Buddhism Bimonthly*, *Minglun*, collections of recitation accounts, contemporary rebirth accounts, and related works.
