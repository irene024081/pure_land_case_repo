# 质量评分表 v1 / Quality Rubric v1

**版本:** 1.0（2026-09-22 建）
**适用范围:** Pipeline `reader_generation` 与 `creator_analysis` 两类产物的质量评测。配套评测集：`data/evaluation/eval_set_v1.json`。
**修改规则:** 本表一经用于基线评分即冻结；任何修改生成新版本（v2），已出的评分报告不重打。

## 通用规则

1. 每个维度打整数分 1–5，分数必须对应锚点描述，不允许"介于两者之间"的 3.5 这类分数。
2. 每条分数必须附一句理由 + 产物原文引文作为证据；没有证据不打分。
3. **评分语境是 brief**：每个评测条目是一个选题 brief（主题/受众/时长），分数回答的问题是"这套产物对这个 brief 的支撑程度如何"。忠实度、结构、节制等产物内在维度不随 brief 变化；法义贴合度、受众明确性、可用性必须结合 brief 的受众与用途判断。
4. 分数方向统一：**5 分永远是最好**。注意"误读风险"维度：5 分 = 风险控制得好，1 分 = 有重大未提示风险。
5. 评分人署名规则见 `README.md`；AI 评分与人工评分分开记录，互不覆盖。

## A. 读者文本（reader_generation）

### A1. 忠实度（硬门槛）

衡量：文本中的事实、归属、不确定性是否全部可追溯到案例事实与来源分段。

| 分 | 锚点 |
|---|---|
| 5 | 全部事实可追溯；自述/他观/编者注等报告者层次完整保留；不确定性（未记名、年代不详）如实交代 |
| 4 | 事实全部可追溯，但个别归属提示被弱化或位置不当，读者需细看才能分清报告者 |
| 3 | 事实可追溯，但有归属被省略（如把"记载称"某人所见写成直接叙述），未构成虚构 |
| 1–2 | （不使用，见下） |
| **0（硬门槛触发）** | 出现任何无证据的场景、心理活动、对话、因果链或教理结论；或把自述瑞相写成经他人证实的事实；或张冠李戴。**触发后该产物整体记 0 分并判定不可用，其余维度不再评** |

### A2. 叙事吸引力

衡量：作为一篇"让人愿意读完、愿意转述"的文章的品质。

| 分 | 锚点 |
|---|---|
| 5 | 开场即进入具体场景或悬念；细节服务于叙事节奏；读完后有想讲给别人听的冲动 |
| 4 | 有明确主线和至少一处亮点细节；整体顺读，仅局部平铺 |
| 3 | 按时间顺序平铺直叙，材料本身有故事性但讲述像内容摘要；无开场设计 |
| 2 | 近乎事实清单，无场景感、无节奏，需要读者自己找重点 |
| 1 | 难以通读，信息组织混乱或文体生硬 |

### A3. 结构清晰度

衡量：段落分工与详略安排。

| 分 | 锚点 |
|---|---|
| 5 | 段落分工明确（背景—转折—结局—出处），详略得当，重点段落一眼可辨 |
| 4 | 顺序清楚、分段合理，但详略平均，最打动人的材料没有被突出 |
| 3 | 顺序清楚但分段琐碎或过长，出处交代打断正文 |
| 2 | 结构可辨但需费力重建事件顺序 |
| 1 | 结构混乱，事件顺序或层次错误 |

### A4. 情感节制

衡量：是否"不煽情、不夸张"，情感是否由事实自然带出。

| 分 | 锚点 |
|---|---|
| 5 | 全文克制，无渲染词、无夸张修饰、无猎奇笔法；动人处靠事实本身 |
| 4 | 基本克制，个别措辞略有文学化但不失实 |
| 3 | 有明显渲染（如"不可思议的伟大奇迹"式评语），但未到煽情程度 |
| 2 | 多处煽情或夸张，情感压倒事实 |
| 1 | 以煽动情绪为主要手法 |

### A5. 术语可懂度

衡量：非专业读者（未受佛学训练的普通信众/读者）能否顺畅读懂。

| 分 | 锚点 |
|---|---|
| 5 | 佛教术语首次出现时即由语境或简短措辞解释清楚；全文用词统一（简/繁一致） |
| 4 | 主要术语可懂，个别生僻词未解释但不影响理解大意 |
| 3 | 有 1–2 处关键术语未解释（如"右胁""行道""入法界品"），普通读者会卡住；或简繁不一致增加阅读成本 |
| 2 | 术语密集且多数未解释 |
| 1 | 不通佛学背景无法读懂 |

## B. 创作角度（creator_analysis）

### B1. 法义贴合度

衡量：角度是否对应法师开示中真实反复出现的讲法主题（如信愿持名、临终关怀与助念、病苦转念、厌离欣求、忏悔、持戒、带领家人共修等），而不是通用主题词或文献学话题。

| 分 | 锚点 |
|---|---|
| 5 | 角度可直接接入法师常讲的主题脉络，法师看到标题就知道可以怎么讲 |
| 4 | 角度对应真实讲法主题，但表述偏学术或偏"举例说明"，需法师自己接上法义 |
| 3 | 一半角度贴合、另一半偏材料学/内部话题；或角度与修行相关但泛化（停留在"念佛好"级别） |
| 2 | 角度多为文献学、证据学话题，与讲法主题只有弱关联 |
| 1 | 角度与法义无关，或完全是项目内部流程话题 |

### B2. 角度区分度

衡量：同一案例的角度之间、以及与其他案例的角度之间是否真正不同。

| 分 | 锚点 |
|---|---|
| 5 | 案例内角度互不重叠；与其他案例的角度相比，标题即可看出差异 |
| 4 | 案例内角度有差异；跨案例有近似但不雷同 |
| 3 | 案例内角度有差异，但跨案例明显模板化（同一类角度换案例名重复出现） |
| 2 | 案例内角度部分重叠，或跨案例几乎同构 |
| 1 | 角度雷同，同一角度换名字重复 |

### B3. 受众明确性

衡量：受众是否具体到处境，且角度内容确实服务该处境。

| 分 | 锚点 |
|---|---|
| 5 | 受众具体到处境（如"家中有临终亲人的居士"），角度的主张、结构、边界都为该处境设计 |
| 4 | 受众较具体（如"助念团成员"），内容与受众处境基本对应 |
| 3 | 受众是笼统分类（"普通读者""在家居士"并列罗列），内容与受众只有弱关联 |
| 2 | 受众标签与内容明显不匹配 |
| 1 | 无有效受众信息 |

### B4. 误读风险

衡量：产物是否预见并锁住了创作者最可能讲错的地方。（5 = 风险控制好）

| 分 | 锚点 |
|---|---|
| 5 | 主要误读路径已逐一识别，并给出可直接引用的边界措辞；创作者照做几乎不会讲错 |
| 4 | 边界声明具体，覆盖了主要风险，但有个别风险路径未提示 |
| 3 | 有边界声明但笼统（"不能证明往生"反复出现而未说明本案例特有的风险） |
| 2 | 风险提示缺失关键环节，创作者有相当可能讲过头 |
| 1 | 存在重大未提示误读风险，或产物本身含有误导性表述 |

### B5. 可用性

衡量：创作者拿到这个角度，能否直接支撑一次开示或一条视频。

| 分 | 锚点 |
|---|---|
| 5 | 开场、结构、关键引文、收尾齐备，创作者几乎不用再设计即可开工 |
| 4 | 结构骨架完整且贴合 brief 的受众与时长，缺开场钩子或关键句，需少量加工 |
| 3 | 有结构骨架，但无开场设计、无讲述要点，创作者需自行再设计一半以上 |
| 2 | 只有主题方向，无法据此组织一场讲述 |
| 1 | 角度本身不成立或对创作者无意义 |

## 汇总方式

- 每个 brief 产出 10 个分数（读者文本 5 维 + 创作角度 5 维）。
- 读者文本触发忠实度硬门槛时，该 brief 的读者侧记 0，创作角度侧照常评。
- 报告须给出：逐 brief 分数表、维度平均分、主要失分模式（失分模式的判定必须有 ≥3 个 brief 呈现同一问题，或属于硬门槛级别）。
