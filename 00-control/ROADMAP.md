- 每个任务标明：**谁做**（AI / 负责人 / 协作者 / 外部）。

4. 外联仍做，但只针对高价值现代来源（如四个 M2 试点），目标是获得更宽的授权。

——负责人定策略，AI 执行逐源版权研究。

```text
  → Phase 1（Pipeline 可信）     ← 一切的地基
      → Phase 2（语料 50-100）   ← 需要 Phase 1 的批量能力
          → Phase 3（后端）      ← 语料进入产品库

[并行线]

```
