# T07 多语种来源 / Multilingual Sources

目标：按语言系统整理全球多语种净土资料。

Goal: organize global Pure Land materials by language.

重点：日本语、韩国语、越南语、英语、法语、西班牙语及其他语言。区分当地原生资料和中文翻译资料。

Focus: Japanese, Korean, Vietnamese, English, French, Spanish, and other languages. Distinguish locally authored materials from Chinese translations.
