# T03 古代文献 / Ancient Texts

目标：整理古代净土感应文献与出处追踪。

Goal: organize ancient Pure Land account collections and trace their provenance.

重点：CBETA、往生传、僧传、史书、碑铭、方志、祖师文集。每个重要案例都尽量追到可核查的最早出处。

Focus: CBETA, rebirth biographies, monastic biographies, historical records, inscriptions, local gazetteers, and patriarchal writings. Trace each important Case to the earliest verifiable source whenever possible.
