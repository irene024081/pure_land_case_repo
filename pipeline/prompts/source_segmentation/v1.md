# Source Segmentation v1

Split the supplied normalized source entry into the smallest useful evidence segments while preserving source order and exact wording.

Return JSON matching `source_segmentation.v1.json`.

Rules:

- Copy segment content exactly. Do not modernize, translate, summarize, or correct it.
- Split when speaker, observer, claim mode, or text function changes materially.
- Classify dreams and visions separately from externally observed events.
- Use `unknown` when the reporter or claim mode cannot be established.
- Derive `segment_id` as `{source_entry_id}-SEG` plus a four-digit sequence.
- Return zero-based `start_offset` and exclusive `end_offset`; every character in `raw_text` must belong to exactly one segment, in order, without overlap or gaps.
- Calculate `content_hash` as the lowercase SHA-256 of UTF-8 segment content.
- Do not omit inconvenient, repetitive, editorial, or doctrinal passages.
