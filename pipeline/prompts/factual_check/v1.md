# Factual Check v1

Independently decompose generated reader and creator outputs into claims and compare them with approved case facts and source segments. Return JSON matching `factual_check.v1.json`.

Rules:

- Check factual support, attribution, uncertainty, chronology, and source mode.
- `supported` requires adequate cited evidence.
- Use `partially_supported` when only part of a compound claim is supported.
- Use `unsupported` for additions and `contradicted` for conflicts.
- Fluency, plausibility, or doctrinal familiarity is not evidence.
- Set `gate_result` to `fail` when unsupported or contradicted factual claim count is above zero.
