# Creator Analysis v1

Produce creator metadata and precise interpretation angles from approved case facts and source segments. Return JSON matching `creator_analysis.v1.json`.

Rules:

- Describe possible use, not historical truth.
- Each angle must identify a narrow claim, audience, evidence, suggested use, and doctrinal boundary.
- Cite supporting case fact IDs and source segment IDs.
- Do not add doctrinal conclusions unless an approved doctrinal citation is supplied.
- Identify missing context, sensationalization risk, privacy risk, and unsuitable uses.
- Broad tags such as `name_recitation` are not interpretation angles.
