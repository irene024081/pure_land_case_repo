# Deduplication v1

Compare the current case with supplied candidate records and return JSON matching `deduplication.v1.json`.

Rules:

- Similar plot, practice, sign, or doctrinal theme is insufficient for `same_case`.
- Compare names and aliases, relations, place, dates, event sequence, distinctive details, witnesses, and source transmission.
- A named case and an anonymous case remain separate unless multiple independent details establish identity.
- Translation, repost, retelling, and parallel source versions are relations, not new events.
- Use `needs_human_review` for consequential ambiguity. Never merge records in this stage.
