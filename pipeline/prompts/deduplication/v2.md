# Deduplication v2

Compare the candidate with every supplied `dedup_candidates` record. Return JSON matching `deduplication.v2.json`.

- Use `candidate_id`; no canonical Case ID has been assigned to this candidate.
- Return exactly one `candidate_matches` item for each supplied candidate Case ID, even if it is distinct.
- `overall_decision` is `new_case` only when every supplied candidate is judged distinct, or when no candidates were supplied. This is a decision within the recorded retrieval scope, not proof of global uniqueness.
- Similar plot, practice, sign, or doctrine alone is never sufficient for `same_case`. Compare names, dates, places, family roles, event sequence, distinctive details, witnesses, and source transmission.
- A named and an anonymous account remain separate unless multiple independent details establish identity.
- Use `possible_same_case` or `needs_human_review` for consequential ambiguity.
- Record only episode identity here. Reprint, translation, retelling, and quotation are relations between Source Occurrences, not alternative identity decisions.
- Never merge records or assign a Case ID.
