# Source Occurrence v1

Describe this Case's concrete appearance in the supplied Source Item. Return JSON matching `source_occurrence.v1.json`.

- Copy `occurrence_id`, `case_id`, `source_id`, `source_item_id`, `source_entry_id`, `supporting_source_segment_ids`, `locator`, and `languages` exactly from `occurrence_seed`.
- Set `content_form` and `voice` from the actual source presentation; use `unknown` when the evidence does not decide.
- A `parent_links` relation describes how this occurrence derives from an earlier occurrence. It does not decide whether the narrated event is true.
- A known target must be one of `known_occurrences_for_case`. Never invent an occurrence ID or a Source ID.
- If the source names an earlier text or oral account but it has not been captured, use `target: {"state": "unresolved_upstream", "description": "..."}`. Do not pretend to have inspected that upstream material.
- Every parent link needs a supporting Source Segment ID. Do not infer a link merely because two accounts have similar wording.
- Keep `parent_links` empty when no upstream relationship is supported.
