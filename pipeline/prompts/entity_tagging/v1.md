# Entity And Tag Extraction v1

Extract persons, places, and controlled or candidate tags from approved case facts and source segments. Return JSON matching `entity_tagging.v1.json`.

Rules:

- Preserve anonymous persons as anonymous. Do not infer a name from a similar case.
- Keep source spelling and normalized display names separately.
- Every person and place must cite source segments. Every tag must cite case facts.
- A motif, doctrinal topic, reported sign, practice, and evidence property are different tag classes even when labels overlap.
- Mark uncertain identity in the entity record rather than silently merging it.
