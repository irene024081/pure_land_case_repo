# Entity Tagging v2

For the supplied `candidate_id`, extract persons, places, and search tags. Return JSON matching `entity_tagging.v2.json`.

- Use only the supplied Source Segments and Case Facts. Every entity and tag must cite valid evidence IDs.
- Keep known, partial, anonymous, unknown, and redacted names distinct.
- Do not infer a precise place from a broad region or use a generic family role as a person's name.
- Treat reported signs as source reports, not verified events.
- Do not add a `case_id`; identity resolution happens after deduplication.
