# Case Extraction v2

Extract atomic statements for the supplied `candidate_id`. Return JSON matching `case_extraction.v2.json`.

- Use `{candidate_id}-FACT` plus a four-digit sequence for `case_fact_id`. A canonical Case ID does not exist yet.
- Preserve who spoke or observed, source attribution, uncertainty, chronology, and dream or vision status.
- Every fact must cite the exact supporting Source Segment IDs. Do not combine independently checkable propositions.
- Describe what the source states; do not assert that a reported religious experience has been independently verified.
- Do not add a `case_id`, decide identity, or infer missing details.
