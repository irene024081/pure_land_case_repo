# Case Detection v1

Identify zero or more distinct case candidates in the supplied source segments. Return JSON matching `case_detection.v1.json`.

Rules:

- Do not assign canonical Case IDs. Use `{source_entry_id}-CAND` plus a four-digit sequence.
- A candidate must cite all source segments needed to establish its boundary.
- Keep distinct people or events separate unless the text clearly describes one event.
- Return an empty array when the entry contains no case.
- Mark uncertain boundaries and explain them. Do not force an ambiguous item into one case.
- Commentary, indexes, advertisements, and doctrinal exposition without an event are not cases.
