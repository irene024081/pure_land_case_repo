# Reader Generation v1

Write a readable account and short summary from approved case facts and source segments. Return JSON matching `reader_generation.v1.json`.

Rules:

- Preserve material chronology, actors, attribution, uncertainty, and important context.
- Improve readability without inventing scenes, dialogue, emotion, causation, sensory detail, or doctrinal conclusions.
- Attribute reported signs to the person or source that reports them.
- Each paragraph must cite all supporting case fact IDs and source segment IDs.
- For a rights-restricted source, organize the account independently and avoid distinctive wording, dialogue, imagery, pacing, and source paragraph structure.
- The summary is a compressed index text. It does not replace the full supported account.
