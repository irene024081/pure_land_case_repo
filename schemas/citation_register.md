# 历史 Citation 字段 / Legacy Citation Fields

`citation_register.md` 是 v0.1 历史字段说明。当前领域实体是 `source_occurrence_register.md` 中的 `SOURCE_OCCURRENCE`；不要为同一次来源出现同时创建 Citation 和 Occurrence。

`citation_register.md` documents the v0.1 fields. The current domain entity is `SOURCE_OCCURRENCE` in `source_occurrence_register.md`; do not create both a Citation and an Occurrence for the same appearance.

旧 `CIT` ID、`citation_role`、`is_primary_citation` 和定位字段的迁移规则见 `../02-data-model/T02_V02_MIGRATION.md`。历史 M2A 产物和旧 Pipeline Contract 不作原地修改。

Migration rules for old `CIT` IDs, `citation_role`, `is_primary_citation`, and locators are in `../02-data-model/T02_V02_MIGRATION.md`. Historical M2A outputs and old Pipeline Contracts remain unchanged.
