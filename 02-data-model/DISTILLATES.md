# 蒸馏物定义与清单 / Distillates: Definition And Registry

**状态：** 提议级（2026-09-22 负责人在讨论中提出方向，明确说不一定全是正式需求；待负责人逐项确认后升级）。
**背景：** 负责人提出——AI 辅助创作的质量取决于对"法师讲稿 / 经典原文 / 往生资料 / 祖师评论"的大规模阅读，但只有 AI 有这个阅读量；因此语料必须先消化成可审查的中间产物，再注入 prompt 起作用。

## 1. 定义

**蒸馏物（distillate）**= 从语料中提炼的、供 prompt 或产品使用的中间产物。必须同时满足五个条件：

1. **从语料来**：每条结论可追溯到具体语料出处；
2. **人审得过**：体积小到一个真人能完整读完并批改——这是与原始语料的本质区别；
3. **有版本**：修改留痕，可对比、可回退；
4. **有明确用途**：写明注入哪个 prompt / 哪个功能；没有用途的提炼不做；
5. **有更新机制**：语料增加后有明确的增量更新方式。

**不算蒸馏物的：** 原始语料（体量超人审能力、多有版权限制）；AI 分析时的中间笔记（过程产物）。

## 2. 分工原则

```text
语料（海量，AI 读）
   ↓ AI 提炼 + 人工审查
蒸馏物（少量，人审）
   ↓ 注入版本化 prompt / 产品功能
生成物（每条过独立检查）
```

语料永不直接进入 prompt；只有审过的蒸馏物进入。AI 负责读和提议，人负责裁决，蒸馏物是两者之间的界面。
