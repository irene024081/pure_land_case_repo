# 蒸馏物定义与清单 / Distillates: Definition And Registry

**状态：** 已随 2026-09-24 负责人《内容质量与 Prompt 体系总体 Guideline v0.5》（存档：`notes/guideline/`）升级——蒸馏物合格条件从五条扩为八条，清单与七个 Prompt（P1–P7）挂钩。

## 1. 定义

**蒸馏物（distillate）**= 从语料中提炼的、供 prompt 或产品使用的中间产物。合格条件（v0.5 八条）：

1. **从语料来**：每条结论可追溯到具体语料出处；
2. **人审得过**：体积小到一个真人能完整读完并批改；
3. **可追溯**：重要结论能回到具体 source / span / 对照样本；
4. **类型明确**：经典原文、祖师解释、当代法师解释、听众问题、编辑规则的认知地位不同，不可混同；
5. **适用范围明确**：传统 / 法脉 / 时代 / 受众 / 语料范围可记录；
6. **有版本**：修改留痕；Prompt 版本能声明自己依赖哪版蒸馏物；
7. **有明确用途**：写明注入哪个 Prompt / 功能；说不清就不建设；
8. **可更新**：新语料或 A/B 结果可以修正，不冻结成"真理"。

**不算蒸馏物的：** 原始语料（体量超人审能力、多有版权限制）；AI 分析时的中间笔记（过程产物）。

**标准生产流程（v0.5 候选漏斗）：** AI 大量阅读并发现候选 → 去重聚类压缩到 20–100 个 → 负责人标注 Good/Bad/Mixed 附极短理由 → AI 从已标注正反例蒸馏"触发条件+动作+边界+对照片段" → 写回具体 Prompt → 同输入 A/B + P7 硬检查 → 稳定改善才保留。**禁止闭环自证：AI 不得用自己生成的范文充当黄金标准。**

## 2. 分工原则

```text
语料（海量，AI 读）
   ↓ AI 提炼 + 人工审查
蒸馏物（少量，人审）
   ↓ 注入版本化 prompt / 产品功能
生成物（每条过独立检查）
```

语料永不直接进入 prompt；只有审过的蒸馏物进入。AI 负责读和提议，人负责裁决，蒸馏物是两者之间的界面。

## 4. 立项规则

新增一种蒸馏物前，先在本文件登记：来源语料、授权状态、注入点、审查人、更新机制。五项不全不立项。
